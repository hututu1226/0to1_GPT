# 记录模板

复制下面的内容，粘到 `docs/工作日志.md` 的「工作日志」一节**最上面**。

---

```markdown
### YYYY-MM-DD · 周X · 3h · ✅

**做了什么**
- 

**产出**
- `stage1-nanogpt/...` 或曲线图路径，或"无"

**卡住**
- 无 / 具体现象（报错、loss 异常、环境问题）

**学到**
- 一两条就行，别写论文

**下次从这开始**
- 
```

---

## 状态标记

| 标记 | 含义 |
|---|---|
| ✅ | 顺利，达成预期 |
| ⚠️ | 卡壳，但有进展 |
| 🚧 | 未完成，留到下次 |
| 💡 | 纯阅读/思考，没有产出 |

## 故障复盘（遇到 loss 异常、环境崩、结果不对时用）

```markdown
### 故障 YYYY-MM-DD

**现象**
（loss 怎么变的、从哪一步开始的、报错原文）

**假设**
1. 
2. 
3. 

**验证**
- 假设 1：怎么试的 → 结果
- 假设 2：怎么试的 → 结果

**结论**
（根因是什么，下次怎么避免）
```
