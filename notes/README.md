## 流程

1. **我写**：想到什么记什么，写在哪都行 —— [_draft.md](_draft.md)、Obsidian、手机备忘录、甚至直接发在聊天里
2. **我说一声**「整理一下笔记」
3. **整理**：搬进对应阶段的笔记文件，补索引，顺手合并重复、挑出错的地方

格式不重要，内容才重要。整理只动结构，不补内容、不下结论。
