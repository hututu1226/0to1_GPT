## 流程

1. **我写**：想到什么记什么，写在哪都行 —— [_draft.md](_draft.md)、Obsidian、手机备忘录、甚至直接发在聊天里
2. **我说一声**「整理一下笔记」
3. **整理**：搬进 `notes/bX-课程名.md`，补索引，顺手合并重复、挑出错的部分

格式不重要，内容才重要。整理是整理结构，不会替你补内容、也不会替你下结论。
