## 怎么记

**每学完一节，花 5 分钟填一份**，复制 [TEMPLATE.md](TEMPLATE.md)，命名为 `b2-自动求导.md` 这种。

三条原则：

1. **别抄书**。课件里已经有的东西不用再写一遍，写课件里没有的。
2. **重点记「我错过的」**。凡是自己答错、报错、想歪的地方，一定要写进去——那才是你真正缺的东西。
3. **只写能在 30 秒内扫完的量**。写长了以后不会看，等于没写。

## 怎么找

- **看索引**：上面那张表，一眼知道哪节学过
- **全局搜**：VS Code 里 `Ctrl + Shift + F`，搜关键词（比如 `广播`、`zero_grad`），会同时搜到笔记和 notebook

## 和 notebook 的分工

| | 放什么 |
|---|---|
| **notebook** | 完整讲解、可运行示例、练习 |
| **笔记** | 压缩后的一页纸：结论、坑、速查、待解疑问 |

笔记是给三个月后的自己看的，不是给现在的自己看的。
