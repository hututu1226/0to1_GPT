## 为什么要这一段

阶段 ① 一上来就要读 nanoGPT 的 `model.py`，里面全是张量变形、`backward()`、`nn.Module`。如果这些不熟，读代码会变成"每行都认识、连起来不知道在干嘛"。

补完这五节，读 `model.py` 是"看代码"，不是"猜代码"。

**预计 20 小时**，分五次，每次 3–5 小时。不用一次做完。

## 怎么用

每节课的文件都是**能直接跑的**：

```powershell
.venv\Scripts\python.exe stage0-basics\b1_tensor.py
```

文件的结构固定：

1. **讲解段** —— 跑起来会打印出说明和示例
2. **示例** —— 可以直接改数字再跑
3. **练习** —— 文件末尾有填空，填完会自动判对错

练习没做对不会中断，只会打 `✗`。全部 `✓` 就算这节过了。
