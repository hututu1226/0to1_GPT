# 阶段 ⓪ · PyTorch 基础

## 为什么要这一段

阶段 ① 一上来就要读 nanoGPT 的 `model.py`，里面全是张量变形、`backward()`、`nn.Module`。如果这些不熟，读代码会变成"每行都认识、连起来不知道在干嘛"。

补完这五节，读 `model.py` 是"看代码"，不是"猜代码"。

**预计 20 小时**，分五次，每次 3–5 小时。不用一次做完。

## 怎么用

用 **VS Code** 打开仓库文件夹，点开 `stage0-basics/b1_tensor.ipynb`。

右上角点 **Select Kernel**，选 **`0to1_GPT (Python 3.12)`**，或者直接选 `.venv\Scripts\python.exe`。

> 仓库里带了 `.vscode/settings.json`，默认就指向这个 venv，通常不用手选。

每节课的结构固定：

1. **讲解格子** —— Markdown，直接读
2. **代码格子** —— `Shift + Enter` 运行，可以直接改数字再跑
3. **练习格子** —— 文件末尾，改标了 `← 改这一行` 的地方，再跑那一格
